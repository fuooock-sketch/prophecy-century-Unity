## 一、游戏胜利与失败条件

### ✅ 胜利条件
玩家抵达第 15 层 Boss 节点「深渊王座」并在战斗中获胜 → 直接触发 `Victory`。

### ❌ 失败条件
任意一场战斗失败 → 立即 `GameOver`（当前没有复活/续局机制）。

| 场景 | 结果 | 流程 |
|------|------|------|
| 击败 Boss | 🟢 Victory | 通关结算，Boss 奖励发放 |
| 任意战斗失败 | 🔴 GameOver | 立即结束，不进入下一回合 |
| 非 Boss 节点完成 | 进入经营回合 | 发放节点奖励 → NextRound → 经营阶段 |
| 资源/宝物节点 | 进入经营回合 | 立即发放 → 无战斗 → 经营阶段 |

## 三、节点分布与路线设计

### 3.1 节点类型统计

| 类型 | 数量 | 说明 |
|------|------|------|
| start | 1 | 起点「营地篝火」Layer 0 |
| battle | 26 | 普通战斗，覆盖 L1-14 每层 |
| resource | 13 | 资源节点，纯金币收益 |
| treasure | 9 | 宝物节点，全局被动道具 |
| boss | 1 | Boss「深渊王座」Layer 15 |

### 3.2 三条典型路线

| 路线 | 战斗次数 | 金币总量 | 宝物数 | 体验 |
|------|---------|---------|--------|------|
| **全战斗** | 14 | ~75金 | 0 | 硬核，阵容检验充分 |
| **均衡** | 8-10 | ~60金 | 4-5 | ⭐ 推荐，攻守兼备 |
| **纯资源+宝物** | 1(Boss) | ~35金 | 5 | 高隐含风险：金币少→后期阵容弱 |

> ⚠️ **软强制设计：** 纯资源路线看似安全，但战斗节点奖励高于资源节点，导致后期金币不足。这是一种「软强制」设计，鼓励玩家在路线选择上有策略深度而非简单避战。

### 6.2 叙事弧设计

> 🎢 **叙事弧：** 教学（R1-2）低开 → 展开-最宽（R3-7）持续上升 → **合成低谷**（R8-9）受挫回调 → V 型回升（R10-12）重建巅峰 → Boss（R13-15）高潮释放。

### 6.3 关键设计转折点

| 转折 | 位置 | 设计意图 |
|------|------|----------|
| ① 首杀快感 | R1-2 | 轻松获胜 → 建立信心 → 引入宝物概念 |
| ② 战略觉醒 | R3-4 | 分支有意义 → 新敌人类型（刺客）→ 需要调整策略 |
| ③ 阵容成型 | R5-7 | 协同技能爆发 → 武学大师入场 → 感受强力组合乐趣 |
| ④ **合成低谷** | R8-9 | 合成消耗低星单位 → 阵容暂时减员 → 焦虑 → 刺激后续重建动机 |
| ⑤ V 型回升 | R10-12 | 高星单位补位 → 恶兆之心获取 → 阵容重新强化 → 超过之前峰值 |
| ⑥ 终局释放 | R13-15 | 最后补给 → Boss 前最后一战 → 击败 Boss → Victory 情感释放 |

> 💡 **「合成低谷」是刻意设计的情绪锚点：** 玩家在 R5-8 快速拉升后，合成三★1→★2 会暂时减少棋盘单位数，导致短期战力下降。这个「暂时变弱」的焦虑期让后续的 V 型回升更有满足感。如果测试发现低谷太深导致挫败，可通过增加 R8-10 宝物密度软性补偿。
