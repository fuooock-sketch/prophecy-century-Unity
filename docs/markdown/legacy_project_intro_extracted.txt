
预言世纪项目介绍
项目概述
《预言世纪》是一款以中世纪奇幻世界为背景的策略自走棋 Roguelite 游戏。玩家在一局冒险中招募部队、经营资源、构筑阵容，并通过世界地图上的分支路线不断面对战斗、事件、商店和资源节点，最终挑战地图深处的 Boss。
项目的核心目标是把“自走棋阵容构筑”的成长感，和“Roguelite 路线选择”的决策压力结合起来。玩家每一天都需要在有限资源和有限移动力下做选择：是追求更高收益、挑战精英敌人，还是稳健发育、为夜晚经营阶段保留更好的阵容空间。
一句话定位
一款围绕部队构筑、世界地图探索与自动战斗展开的中世纪奇幻策略 Roguelite。
核心体验
玩家在《预言世纪》中主要体验三件事：
在世界地图上选择路线，判断风险、收益和推进节奏。
在经营阶段购买、合成、部署单位，形成稳定或爆发型阵容。
在自动战斗中验证阵容强度，并根据胜负反馈继续调整策略。
游戏希望让玩家感受到“每一步路线选择都会影响后续经营，每一次经营决策都会影响下一场战斗”的连续策略体验。
世界观与气质
《预言世纪》的世界围绕预言、王国、信仰、种族与战争展开。不同种族和信仰的部队在同一场冒险中被玩家招募、组合并投入战场。
整体气质偏向暗黑奇幻和史诗战役：
预言指向即将到来的时代危机。
各阵营在战争中寻找生存与扩张的机会。
玩家扮演的指挥者需要在有限时间内积累力量，击败关键敌人。
玩法循环
一局游戏的主循环由“白天探索”和“夜晚经营”组成：
开局选择英雄或初始路线。
白天在世界地图上消耗移动力，前往相邻节点。
节点可能触发普通战斗、精英战斗、资源奖励、商店或随机事件。
白天获得的金币、卡牌、宝物和临时增益会进入后续经营。
夜晚进入经营阶段，玩家购买单位、刷新商店、合成升星、调整站位。
经营结束后进入新的一天，移动力恢复，地图探索继续推进。
最终抵达并击败 Boss，完成本局冒险。
这个循环让游戏在节奏上形成两种互补体验：
白天偏冒险、路线判断和风险承担。
夜晚偏思考、资源转化和阵容优化。
战斗系统
战斗采用自动战斗形式，玩家在战斗前完成部署，战斗开始后由单位根据规则自动行动。
当前战斗设计关注以下要素：
六边形战场站位。
单位数量与单体血量。
攻击、防御、伤害、速度、先机、士气、幸运、射程等属性。
种族、信仰、职业带来的阵容辨识度。
冲锋、扑击、追击、召唤、光环等表现型战斗技能。
玩家的关键决策不是临场微操，而是战前构筑：选择哪些单位、如何升星、如何站位、如何围绕技能和属性形成战斗节奏。
经营与构筑
夜晚经营阶段是阵容成长的主要场所。玩家可以：
使用金币购买单位。
刷新商店寻找关键卡。
将单位部署到棋盘。
通过三合一机制提升星级。
调整阵容站位。
利用宝物、事件奖励和临时增益强化队伍。
经营阶段会完整承接白天探索的收益。白天获得越多资源，夜晚就越有空间完成阵容升级；但高收益路线往往伴随更高战斗风险。
世界地图系统
世界地图采用分支路径结构。玩家从起点出发，沿着节点和连线逐步前进。
地图节点包括：
起点：一局冒险的初始位置。
普通怪物：标准战斗，提供基础奖励。
精英怪物：更高难度战斗，提供更高价值奖励。
资源点：直接获得金币、宝物或临时增益。
商店：在地图层面进行购买或补给。
随机事件：提供多选项事件，改变资源、战斗或路线。
Boss：最终挑战，胜利后通关。
世界地图让每局游戏形成不同路线。玩家需要在安全发育、挑战高收益节点和尽快推进 Boss 之间做权衡。
当前开发状态
项目目前已经具备 Unity 原型基础，并持续围绕战斗表现、运行时 UI 和世界地图系统推进。
已具备或正在完善的方向包括：
Unity 运行时 UI 框架。
单位卡牌、棋盘、商店、手牌等经营界面。
自动战斗系统与战场表现。
单位 tooltip、战斗飘字、hover 信息展示。
单位数据与数值表导入流程。
世界地图与昼夜双阶段系统设计文档。
当前重点是将既有经营自走棋流程，扩展为带有世界地图探索与昼夜节奏的一局完整 Roguelite 流程。
后续规划
后续开发可以按以下方向推进：
实装世界地图数据结构与节点运行状态。
建立昼夜阶段切换控制器。
将现有经营阶段接入夜晚流程。
将战斗节点、资源节点、商店节点和事件节点接入地图。
建立宝物系统和地图事件系统。
完善 Boss 节点、通关结算和失败结算。
优化地图 UI、节点 tooltip、奖励预览和路径反馈。
建立更稳定的数据配置与测试工具链。
项目愿景
《预言世纪》希望提供一种紧凑但有深度的策略体验：玩家不是单纯堆数值，而是在不断变化的地图、资源和敌人压力下，逐步塑造自己的军队。
每一局冒险都应该产生清晰的成长曲线：
开局资源有限，阵容尚未成型。
中期通过路线选择和经营决策建立核心组合。
后期面对高强度节点和 Boss，检验整局游戏的构筑成果。
最终目标是让玩家在一次次失败、调整和通关中，形成对单位、路线、经济和战斗节奏的理解，并愿意用不同阵容重新挑战。
