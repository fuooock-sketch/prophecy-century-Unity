# 《预言世纪》Onepage 介绍图制作说明

> 版本：2026-06-06 v1.0  
> 用途：用于制作游戏 onepage 介绍图，解释核心玩法乐趣，而不是单纯罗列系统流程。  
> 适用对象：策划、美术、程序、AI 出图、飞书文档封面/项目介绍页。

---

## 一、这张图要解决的问题

这张图的目标不是说明“游戏有白天、夜晚、战斗三个阶段”，而是让读者一眼理解：

**《预言世纪》的核心乐趣来自“夜晚经营构筑”，地图探索提供风险和资源，自动战斗负责验证构筑结果。**

因此，图的重点应该从“流程平均展示”调整为“核心玩法权重展示”。

---

## 二、核心表达

### 2.1 主命题

推荐主标题：

> 经营构筑，决定每一场战斗

备选标题：

> 预言世纪：以夜晚经营为核心的路线构筑 Roguelite

### 2.2 副标题

推荐副标题：

> 白天选择风险路线，夜晚用有限资源成长军队，自动战斗验证你的阵容判断。

### 2.3 一句话定位

> 每一天都在世界地图上做风险选择，每一夜都用有限资源重构军队，然后用自动战斗验证你的判断。

---

## 三、信息权重

整张图的信息占比应按以下比例设计：

| 模块 | 占比 | 作用 |
|---|---:|---|
| 夜晚经营 | 50% | 核心成长手段，玩家主要策略决策发生处 |
| 白天地图 | 25% | 提供路线选择、风险压力、奖励来源 |
| 自动战斗 | 25% | 验证经营结果，决定推进或失败 |

不要把三个阶段做成完全等权重的横向流程图。经营阶段必须是画面主体。

---

## 四、推荐版面结构

### 4.1 总体结构

建议使用“中心经营 + 左右因果”的结构：

```text
左侧：白天地图风险选择
        ↓
中央：夜晚经营构筑，占画面最大面积
        ↓
右侧：自动战斗验证
        ↓
底部：胜利推进 / 失败终局 / 进入下一天
```

### 4.2 画面布局

| 位置 | 内容 | 视觉重点 |
|---|---|---|
| 顶部 | 标题、副标题 | 明确游戏卖点 |
| 左侧 25% | 世界地图、分叉路线、节点奖励 | 风险选择 |
| 中央 50% | 夜晚营地、商店、棋盘、金币、合成、站位 | 核心经营 |
| 右侧 25% | 战场、敌我阵容、自动交战 | 构筑验证 |
| 底部 | 循环箭头、胜败结果 | 单局循环 |

---

## 五、夜晚经营必须表达的内容

夜晚经营是核心成长手段，图中不能只写“夜晚经营”四个字，必须拆成玩家真实决策。

### 5.1 必须出现的经营行为

| 行为 | 图中表达方式 | 说明 |
|---|---|---|
| 买谁 | 商店候选单位 + 金币消耗 | 用有限金币补强阵容 |
| 上谁 | 棋盘上阵位 | 上阵位有限，决定当前战力 |
| 升谁 | 三个相同单位合成为高星单位 | 体现长期成长和关键单位培养 |
| 站哪 | 前后排站位格 | 体现保护核心、承伤、输出位置 |
| 留不留钱 | 金币图标 + 当前战力箭头 | 体现当前强度与后续成长取舍 |

### 5.2 推荐中心画面

中央画面可以设计为一个夜晚营地中的战棋经营面板：

- 左下角：金币与商店候选单位。
- 中央：玩家棋盘，多个单位站在格子上。
- 下方：三合一升星提示。
- 右侧：上阵阵容预览或战力变化箭头。
- 背景：营火、帐篷、军旗、装备架，强化“夜晚整军”的氛围。

---

## 六、白天地图要表达的内容

白天地图不是主玩法本体，而是给经营提供压力和资源。

### 6.1 需要表达的决策

| 决策 | 图中表达方式 |
|---|---|
| 走稳妥路线 | 安全节点、较少奖励 |
| 走高收益路线 | 奖励节点、资源图标 |
| 走高风险路线 | 战斗节点、危险标记、通向 Boss 的压力 |

### 6.2 地图模块文案

推荐短标签：

> 白天：选择风险路线

辅助短句：

> 路线决定奖励、压力和下一夜的经营空间。

---

## 七、自动战斗要表达的内容

自动战斗的重点不是玩家操作，而是验证经营判断。

### 7.1 需要表达的反馈

| 战斗结果 | 表达 |
|---|---|
| 胜利 | 获得奖励，进入下一轮经营 |
| 失败 | 本局结束，回到英雄选择 |
| Boss 胜利 | 本局通关 |

### 7.2 战斗模块文案

推荐短标签：

> 战斗：验证阵容判断

辅助短句：

> 你不微操战斗，战斗给出构筑答案。

---

## 八、整体循环表达

推荐用底部循环箭头表达：

```text
地图选择 → 获得资源/承受风险 → 夜晚经营成长 → 自动战斗验证 → 胜利进入下一天 / 失败本局结束
```

图中可以写成更短的版本：

> 资源与风险进入经营，经营结果决定战斗，战斗结果推动下一天。

## 十、视觉风格建议

### 10.1 美术方向

- 中世纪奇幻。
- 暗色羊皮纸地图。
- 夜晚营地与战棋经营界面结合。
- 金色 UI 线框。
- 红色用于危险、Boss、失败压力。
- 蓝色或冷白用于玩家阵容。

### 10.2 构图气质

应像“游戏核心玩法说明页”，不要像市场宣传海报。

避免：

- 阶段平均排列，导致经营阶段不突出。
- 大量小字，导致图不可读。
- 只画角色和城堡，不解释玩法。
- 写入当前 MVP 尚未完成的功能。

---

## 十一、当前版本不应写入的内容

为了避免和当前实现范围产生误解，onepage 暂时不要写以下内容：

- 商店节点。
- 随机事件。
- 精英节点。
- 卡牌奖励。
- 临时 Buff。
- 复杂宝物联动。
- 完整技能体系承诺。

这些可以作为未来扩展图或 Roadmap 图单独表达。

---

## 十二、AI 出图提示词方向

如果使用 AI 生成图片，推荐提示词重点如下：

```text
Create a 16:9 one-page game introduction infographic for a medieval fantasy strategy auto-battler roguelite named "预言世纪 Prophecy Century".

The central 50% of the image must show the night management phase as the main gameplay: a tactical board in a night camp, shop units, gold cost, deployed units, merge-upgrade hint, formation positioning, and resource tradeoff.

The left 25% shows daytime world-map route choice: branching map nodes, safe route, reward route, risky battle route.

The right 25% shows auto battle validation: player formation versus enemy formation, automatic clash, victory advances to next day, defeat ends the run.

Main title text: "预言世纪 Prophecy Century"
Main slogan text: "经营构筑，决定每一场战斗"
Subtitle text: "白天选择风险路线，夜晚用有限资源成长军队，自动战斗验证你的阵容判断。"

Use concise large Chinese labels only:
"白天：选择风险路线"
"夜晚：经营构筑军队"
"战斗：验证阵容判断"
"买谁" "上谁" "升谁" "站哪" "留不留钱"

```

## 十三、验收标准

一张合格的 onepage 应满足：

| 标准 | 判断方式 |
|---|---|
| 经营阶段是否是主视觉 | 中央区域最大，且内容最丰富 |
| 是否说明了玩家为什么好玩 | 能看出买、上、升、站、资源取舍 |
| 地图是否服务经营 | 能看出路线带来资源和风险 |
| 战斗是否服务验证 | 能看出战斗是自动验证构筑 |
| 是否符合当前 MVP | 没有写入未完成系统 |
| 是否可读 | 缩小预览仍能读出主标题和三大模块 |
