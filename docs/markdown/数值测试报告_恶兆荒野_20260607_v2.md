## 一、核心修正：真实游戏战力公式

### 修复前 ⚠
- 估算公式：`(HP+ATK+DEF)/3 × (1+(star-1)×0.3)` —— 严重低估高端单位
- Boss 估算战力：1486（估算）→ 实际游戏分数：**1020**
- 玩家终局战力：8259 → Boss仅 **1035**，差距 **8:1**

### 修复后 ✅
- 使用真实公式：`Attack×1.85 + Defense×1.25 + Power×18 + MaxHp×0.58 + Speed×0.72 + Morale×9 + Luck×5`
- Boss 真实分数：**5820**
- 末日先驱真实分数：**1862**（L11-L14）
- 堕落圣殿真实分数：**1274**（L9-L12）
