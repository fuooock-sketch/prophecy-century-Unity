## 一、核心概念与愿景

### 1.1 游戏一句话描述

> 玩家选择英雄，在分支路径式世界地图上白天探索获取资源，入夜后在营地经营自走棋阵容，最终击败地图深处的 Boss 获得胜利。

### 1.2 核心体验循环

```
                  ┌─────────────────┐
                  │   开局选择英雄    │
                  └────────┬────────┘
                           ▼
          ┌────────────────────────────────┐
          │                                │
          ▼                                │
   ┌──────────────┐                ┌──────────────┐
   │  白天·探索    │ ──移动力耗尽──▶ │  入夜·经营    │
   │  世界地图     │                │  商店/合成    │
   │  战斗/事件    │ ◀──新的一天──── │  部署/调整    │
   └──────────────┘                └──────────────┘
          │                                │
          ▼                                ▼
     击败 Boss ──────────────────────▶ 通关胜利
```

### 1.3 设计哲学

| 原则 | 说明 |
|------|------|
| **节奏分明** | 白天探索紧张，夜间经营从容，两种节奏交错 |
| **选择有意义** | 地图分支路径带来不同的资源/风险权衡 |
| **英雄是核心** | 英雄选择影响探索和经营两个维度的策略 |
| **循序渐进** | 随着天数推进，敌人变强，玩家阵容也在成长 |
| **小步迭代** | 复用现有经营系统，地图系统独立开发，降低风险 |

## 二、整体游戏循环

### 2.1 一局游戏的生命周期

```
第 1 天        第 2 天        第 3 天        ...        最后一天
┌─────┐      ┌─────┐      ┌─────┐                  ┌─────┐
│白天  │      │白天  │      │白天  │                  │白天  │
│探索  │      │探索  │      │探索  │                  │探索  │
│ ↓   │      │ ↓   │      │ ↓   │                  │ ↓   │
│入夜  │      │入夜  │      │入夜  │                  │Boss  │
│经营  │      │经营  │      │经营  │                  │战斗  │
└─────┘      └─────┘      └─────┘                  └─────┘
                                                        ↓
                                                   通关结算
```

### 2.2 单日流程详解

| 步骤 | 阶段 | 玩家行为 | 系统行为 |
|------|------|----------|----------|
| 1 | **白天开始** | - | 恢复移动力到最大值 |
| 2 | **探索移动** | 查看地图，选择相邻节点移动 | 消耗 1 移动力，移动到目标节点 |
| 3 | **节点结算** | 根据节点类型进行对应操作 | 触发战斗/拾取资源/商店交易/事件 |
| 4 | **继续探索** | 重复 2-3，直到移动力归零 | 移动力不足时高亮"入夜"按钮 |
| 5 | **主动入夜** | 点击"入夜"按钮 | 切换到经营阶段 |
| 6 | **夜间经营** | 商店购买、合成、部署等 | 现有经营系统完整运行 |
| 7 | **结束经营** | 点击"结束经营" | 保存阵容状态，天数+1，进入步骤 1 |

### 2.3 关键规则

- 移动力归零后**不能继续移动**，只能入夜
- 入夜是**主动操作**（允许玩家在移动力耗尽前提前入夜）
- 经营阶段结束后**自动**进入下一天的白天
- 未探索的节点在抵达相邻节点前保持**隐藏状态**

## 三、英雄系统

### 3.1 开局选择

- 游戏开始时展示英雄选择界面（已有 HeroSelectionModal）
- 每个英雄有：
  - **外观标识**（名称、称号、符文图标、阵营色）
  - **被动能力**（对探索阶段产生影响的常驻效果）
  - **主动技能**（每天可使用有限次的强力效果）

### 3.2 英雄对探索阶段的影响（被动）

表现在世界地图层面，让不同英雄的探索节奏产生差异：

| 影响维度 | 典型效果示例 |
|----------|-------------|
| 移动力 | 每日移动力+1 |
| 战斗 | 白天第一场战斗全员攻击+2 |
| 收益 | 资源节点额外获得 1 金币 |
| 视野 | 可提前看到相邻节点的类型 |
| 恢复 | 入夜时恢复 5 点生命值 |

### 3.3 英雄主动技能

- 每天可使用 **1 次**（或特定充能条件）
- 可在世界地图上任意时刻触发
- 效果示例：
  - 本场战斗全员获得护盾
  - 立即获得 2 点移动力
  - 跳过当前节点的战斗（消耗移动力但不战斗，拿减半奖励）

### 3.4 英雄与经营阶段的关联

现有经营系统已有 `heroState`（英雄运行时状态），英雄也可通过以下方式影响经营：
- 特定英雄在经营阶段获得额外金币收入
- 英雄的阵营/信仰影响商店出现特定单位概率

## 四、世界地图系统

### 4.1 设计理念

采用 **Slay the Spire 风格的分支路径地图**：

- 地图由**节点（Node）**和**连接线（Edge）**组成
- 玩家从起点出发，每次移动到**相邻的下层节点**
- 每层有 2-4 个节点可选，形成分支决策
- MVP 第一版玩家不可后退，也不做同层横向移动；每次只能沿连接前进到下一层节点

### 4.2 地图结构示意

```
         [起点]             ← 第 0 层（开局位置）
        /  |  \
     [怪] [资源] [怪]        ← 第 1 层
      |    |    / \
     [精] [店] [怪] [事]     ← 第 2 层
      |    |    |    |
     [店] [怪] [精] [怪]     ← 第 3 层
       \   |   |   /
        └──┼───┼──┘
          [Boss]            ← 最终层

  图例：
  [起点] = 起始节点
  [怪]   = 普通怪物
  [精]   = 精英怪物
  [资源] = 资源点
  [店]   = 地图商店
  [事]   = 随机事件
  [Boss] = 首领
```

### 4.3 节点类型定义

| 节点类型 | 图标 | 描述 | 战斗 | 奖励 |
|----------|------|------|------|------|
| **起点** | ★ | 初始位置，无事件 | 无 | 无 |
| **普通怪物** | ⚔ | 标准难度的自动战斗 | 有 | 金币 + 卡牌选择 |
| **精英怪物** | ⚔+ | 高难度战斗 | 有 | 更多金币 + 宝物 |
| **资源点** | ◆ | 直接拾取资源 | 无 | 金币/宝物/临时增益 |
| **商店** | $ | 使用金币购买 | 无 | 购买卡牌/宝物 |
| **随机事件** | ? | 触发随机事件 | 视事件而定 | 多样 |
| **首领** | ☠ | 关卡 Boss | 有 | 通关 |

### 4.4 节点交互流程

```
玩家点击相邻可用节点
        │
        ▼
  展示节点信息（类型、预估难度、可能奖励）
        │
        ▼
  确认移动（消耗 1 移动力）
        │
        ▼
  英雄移动到节点（动画）
        │
        ▼
  ┌──── 节点类型分发 ────┐
  │                      │
  ▼                      ▼
战斗节点              非战斗节点
  │                      │
  ▼                      ▼
进入战斗阶段          展示事件/获得奖励
  │                      │
  ▼                      ▼
战斗结果结算          资源立即到账
  │                      │
  └────────┬─────────────┘
           ▼
     节点标记为"已清除"（不可重复获得奖励）
           │
           ▼
  检查剩余移动力 → 可继续探索或入夜
```

### 4.5 移动力规则

- **每日基础移动力**：4 点（可通过英雄被动或宝物提升到 5-6 点）
- **移动到相邻节点**：消耗 1 点
- **MVP 第一版规则**：所有可移动节点统一消耗 1 点移动力
- **精英与 Boss**：不额外消耗移动力，难度和收益通过战斗配置与奖励体现

### 4.6 节点可见性

- 初始显示：起点 + 第一层所有节点
- **连接可见**：到达某节点后，显示其相邻下层节点
- **节点类型**：默认隐藏，到达相邻节点后揭示类型图标
- **英雄特殊能力**：特定英雄可提前看到相邻节点的具体内容

## 五、昼夜循环系统

### 5.1 设计理念

昼夜切换是游戏节奏的核心控制器：
- **白天** = 冒险、战斗、资源获取、风险承担
- **入夜** = 思考、经营、阵容优化、策略调整

两个阶段互为因果：白天获得的资源在夜间转化为战斗力，夜间的阵容强度决定明天能走多远。

### 5.2 状态机

```
┌──────────┐   移动力耗尽/主动触发   ┌──────────┐
│  白天探索  │ ──────────────────▶ │  入夜经营  │
│  (DAY)    │                      │  (NIGHT)  │
└──────────┘                      └──────────┘
      ▲                                  │
      │       经营结束自动切换              │
      └────────────────────────────────┘
```

### 5.3 白天阶段

**入口条件**：新的一天开始（或第一局开始）

**玩家可用操作**：
- 查看世界地图
- 点击相邻可用节点移动
- 查看英雄信息（被动/主动技能状态）
- 查看背包（宝物/道具）
- 点击"入夜"按钮（移动力归零后高亮提示）

**系统规则**：
- 英雄被动能力持续生效
- 每进入一个新节点，自动结算节点事件
- 战斗中不能入夜
- 移动力 >0 时也可以提前入夜（放弃剩余移动力）

### 5.4 入夜经营阶段

**入口条件**：玩家点击"入夜"按钮

**阶段内容**：完全复用现有经营系统
- 商店刷新、购买单位
- 手牌管理、部署到棋盘
- 三合一合成
- 出售单位
- 英雄资源管理

**阶段结束**：
- 玩家点击"结束经营"按钮
- 自动保存当前阵容
- 天数 +1
- 恢复移动力到最大值
- 进入下一天白天

### 5.5 天数推进的影响

| 天数 | 怪物难度 | 商店星级 | 说明 |
|------|---------|---------|------|
| 1-2 | 基础 | 1-2 星 | 热身阶段 |
| 3-5 | 逐渐提升 | 2-4 星 | 阵容成型期 |
| 6-8 | 较强 | 3-5 星 | 需要策略配合 |
| 9+ | 高强度 | 4-6 星 | 挑战 Boss 前的冲刺 |

Boss 节点的位置应设计在玩家**大约第 8-12 天**可以到达的层数。

## 六、战斗系统

### 6.1 概述

世界地图上的战斗**完全复用**现有的自动战斗系统（`BattleStubSystem`），核心改动在于：
- 敌人阵容从**随机生成**改为**节点配置**
- 不同节点类型提供**不同的战斗体验**

### 6.2 战斗触发

| 触发方式 | 说明 |
|----------|------|
| 进入怪物节点 | 自动触发战斗 |
| 进入精英节点 | 自动触发战斗 |
| 进入 Boss 节点 | 自动触发战斗 |
| 事件触发 | 部分随机事件会触发战斗 |

### 6.3 敌人配置

**普通怪物节点**：
- 从 `unit_data.json` 按天数/星级范围随机抽取
- 敌人数量：2-4 个单位
- 设计原则：略低于当前推荐战斗力，让玩家有成长感

**精英怪物节点**：
- 预设精英阵容（固定组合，可带特殊技能）
- 敌人数量：3-5 个单位
- 设计原则：与当前推荐战斗力持平或略高，奖励丰厚

**Boss 节点**：
- 完全预设的 Boss 阵容
- Boss 单位可带专属被动技能（如出场护盾、AOE 伤害等）
- 敌人数量：4-6 个单位
- 设计原则：需要玩家有成型阵容才能挑战

### 6.4 战斗结果

| 结果 | 条件 | 后果 |
|------|------|------|
| **胜利** | 敌方全部消灭 | 获得奖励，标记节点已清除 |
| **平局** | 时间耗尽，我方血量≥敌方 | 判为胜利，但奖励减半 |
| **失败** | 我方全部消灭或时间耗尽血量落后 | 扣除 HP（基于存活敌人数），节点**未清除**，可再次挑战 |

### 6.5 战斗奖励

| 节点类型 | 胜利基础奖励 | 额外可能奖励 |
|----------|-------------|-------------|
| 普通怪物 | 金币 + 卡牌选择（3 选 1） | - |
| 精英怪物 | 金币 ×2 + 宝物 | 额外卡牌 |
| Boss | 无（通关条件） | 通关结算 |

## 七、经营系统

### 7.1 概述

入夜后的经营阶段**完整保留**现有系统，不作根本性改动。

### 7.2 保留的子系统

| 子系统 | 功能 | 说明 |
|--------|------|------|
| **商店** | 购买单位、刷新、升级 | 完全复用 `ShopSystem` |
| **棋盘** | 部署、移动、出售单位 | 完全复用 `BoardSystem` |
| **合成** | 三合一生星 | 完全复用 `SynthesisSystem` |
| **事件** | 入场触发、回合事件 | 完全复用 `ManageEventResolver` |
| **手牌** | 持有未部署的单位 | 上限 9 张 |

### 7.3 经营阶段的资源来源

白天探索获得的资源在经营阶段使用：

| 资源 | 白天来源 | 夜间用途 |
|------|---------|---------|
| 金币 | 怪物掉落、资源点、事件 | 购买卡牌、刷新商店、升级商店 |
| 新卡牌 | 战斗奖励选择、商店购买 | 部署到棋盘、合成升星 |
| 宝物 | 精英掉落、宝箱、事件 | 被动增益（战斗/经营双场景） |
| 临时 Buff | 资源点、事件 | 经营阶段使用或下一场战斗生效 |

### 7.4 经营结束后的流转

```
经营结束
    │
    ▼
保存阵容（boardUnits, handCards）
    │
    ▼
清除当日临时 buff（roundTemp 类）
    │
    ▼
天数 +1，移动力恢复
    │
    ▼
商店刷新（为下一天做准备）
    │
    ▼
进入白天探索阶段
```

## 八、资源与经济系统

### 8.1 核心资源一览

| 资源 | 图标 | 描述 | 来源 | 用途 |
|------|------|------|------|------|
| **金币** | 💰 | 基础货币 | 战斗、资源点、事件 | 买卡、刷新、升级商店 |
| **生命值** | ❤ | 英雄生命 | 初始值，经营/事件可少量恢复 | 归零则游戏失败 |
| **移动力** | 👣 | 每日探索步数 | 每日恢复 | 地图移动 |
| **宝物** | 🏆 | 被动增益道具 | 精英战、特殊节点 | 全局被动效果 |
| **单位卡牌** | 🃏 | 可部署的战斗单位 | 战斗奖励、商店 | 组成阵容 |

### 8.2 经济曲线设计

```
天数推进 → 金币获取增加 → 商店解锁更高星级 → 阵容强度提升 → 可挑战更难节点
    ↑                                                              │
    └──────────────── 正反馈循环 ──────────────────────────────────┘
```

**设计约束**：
- 每天玩家大致的金币收入在 **8-15 金币** 之间（含战斗+资源点）
- 购买一张卡牌花费 **3 金币**，刷新商店花费 **1 金币**
- 经营阶段平均可购买 **2-3 张卡牌** + **1 次商店操作**
- 避免金币过度溢出导致经营阶段冗长

### 8.3 宝物系统框架

宝物是**非消耗品**，获得后永久生效（直到本局结束）：

| 宝物类别 | 生效阶段 | 效果示例 |
|----------|---------|---------|
| 探索类 | 白天 | 移动力+1、视野扩展 |
| 战斗类 | 战斗 | 全员攻击+1、首回合护盾 |
| 经营类 | 入夜 | 商店多 1 个槽位、刷新消耗-1 |
| 恢复类 | 入夜 | 每天恢复 3 点生命 |

宝物数量限制：建议 5-8 个槽位（初始 3，可通过特殊事件扩展）

## 九、胜利与失败条件

### 9.1 胜利条件

| 条件 | 说明 |
|------|------|
| **击败 Boss** | 到达 Boss 节点并在战斗中获胜 |

### 9.2 失败条件

| 条件 | 说明 |
|------|------|
| **生命值归零** | 战斗中累计损失 HP 达到上限 |
| **天数耗尽**（可选） | 超过最大天数限制仍未击败 Boss |

### 9.3 无天数限制模式（推荐）

- 不设天数上限，但已清除节点不可重复获得奖励，避免无限刷资源
- **代价**：每过一天怪物难度自动提升，且可获得资源来自有限地图节点
- 设计意图：给予充分自由度，但变相施加压力
- 可后续增加"时限挑战"等变体模式

## 十、UI 框架设计

### 10.1 界面层级

### 10.3 HUD 栏设计

始终可见的顶部信息栏：

```
┌──────────────────────────────────────────────┐
│ [⚔詹姆斯] ❤ 85/100  👣 3/4  💰 24  ☀ 第5天  │
│  [被动: 首战+2攻]          [主动: 可用] [入夜]  │
└──────────────────────────────────────────────┘
```

白天阶段"入夜"按钮在移动力归零时高亮闪烁提示。

### 10.4 世界地图视图

- 节点以图标表示（类型图标 + 已清除/未清除状态色）
- 已通过的路径高亮，未探索的路径灰色
- 当前位置用英雄头像标记
- 相邻可用节点有**高亮边框**提示可点击
- 鼠标悬停节点显示**tooltip**（类型、预估难度）

## 十一、数据配置体系

### 11.1 新增配置文件

| 文件 | 路径 | 内容 |
|------|------|------|
| 地图配置 | `Resources/Data/world_maps.json` | 节点布局、连接、类型、奖励 |
| 宝物定义 | `Resources/Data/treasures.json` | 宝物ID、名称、效果、稀有度 |
| 精英配置 | `Resources/Data/elite_enemies.json` | 精英节点的敌人阵容预设 |
| Boss 配置 | `Resources/Data/boss_enemies.json` | Boss 节点的敌人阵容和技能 |

### 11.2 现有文件扩展

| 文件 | 扩展内容 |
|------|---------|
| `campaigns.json` | 增加 `mapId`、`bossNodeId`、`dayLimit` |
| `heroes.json` | 增加探索被动效果字段、主动技能冷却字段 |
| `game_config.json` | 增加 `baseMovePoints`、`bossLayer` 等地图参数 |

## 附录 B：后续可扩展方向

- **多地图模式**：击败一张地图的 Boss 后可进入更难的下一张地图
- **天气系统**：每天随机天气影响探索（如暴雨减少移动力、晴天额外收益）
- **同伴系统**：地图上可招募 NPC 一同探索，提供额外能力
- **周目系统**：通关后可使用解锁内容重新挑战，敌人更强奖励更好
- **每日挑战**：固定种子 + 特殊规则关卡
